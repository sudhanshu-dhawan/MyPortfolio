# 🌐 Personal Portfolio Website -(https://my-portfolio-ten-beige-44.vercel.app/)
Welcome to my personal portfolio website built using **Next.js**, **shadcn/ui**, and **Tailwind CSS**, and deployed with **Vercel**.  
This website showcases my projects, skills, and professional experience as a full-stack developer.

---

## 📌 Task Objectives

- ✅ Build a modern, responsive, and performant portfolio website.
- ✅ Use **Next.js** for server-side rendering and routing.
- ✅ Style the UI using **shadcn/ui** components powered by **Tailwind CSS**.
- ✅ Deploy the live site using **Vercel**.
- ✅ Ensure clean and well-commented code structure.
- ✅ Showcase technical skills, recent work, and contact information.

## 📁 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **UI Library**: [shadcn/ui](https://ui.shadcn.dev/)
- **Styling**: Tailwind CSS
- **Icons**: react-icons
- **Deployment**: [Vercel](https://vercel.com/)

## 🛠️ How to Run the Project Locally

### 1. Clone the Repository

bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

### 2. Install Dependencies
npm install
# or
yarn install

###3. Run the Development Server
npm run dev
# or
yarn dev

##Project Structure
/app             --> Next.js app directory (pages, layout, routing)
  └── /components --> Reusable UI components
  └── /public     --> Static assets
  └── /styles     --> Global styles (if any)
  └── /lib        --> Utility functions and configurations
  └── /ui         --> shadcn/ui components
